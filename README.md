# 加油记账

记录每次加油金额、按月/按年统计。单用户单设备，数据存在你自己的浏览器里。

**技术栈：** Vite + React 19 + TypeScript + Tailwind v4 + shadcn/ui（`base-nova` 风格）

## 怎么跑

```bash
npm install
npm run dev
```

浏览器打开终端里打印的地址（默认 <http://localhost:5173>）。

## 其他命令

```bash
npm test         # 95 个单元测试
npm run build    # 产出静态 dist/，丢到任何静态托管都能跑
npm run preview  # 本地预览构建产物
```

## 怎么用

- 在「记一笔」填日期和金额，点「记下」。金额只接受最多两位小数的数字（如 `320.50`）。
  带千分位的 `1,240.50`、带符号的 `¥320`、全角数字都会被**明确拒绝**，而不是猜着解析。
- 「本月」是主数字，恒定显示**真实的**当前月合计，不随年份选择器变化。
- 「本年」跟随年份选择器，便于同比。看往年时标题会显示具体年份，不会还写「本年」。
- 柱状图显示所选年份 12 个月的分布，**点柱子**可切换下面明细区显示的月份。
  12 个标签会挤成一团，所以只标 1/4/7/10 月，选中的那个始终显示。
- **选中的那根柱子上方会标出该月金额**（如 `¥1,240.50`），其余月份把鼠标放上去看系统提示。
  只标一根是因为列宽只有约 46px，而 `¥1,240.50` 有 67px 宽——12 个月全标必然互相压住。
- 记下一笔后会**跳到那笔所在的月份**，避免记上个月的账时界面上什么都没变。
- 删除记录：点「删除」后会就地变成「确认删除？」，避免误触。
- 右上角可切换深色模式，默认跟随系统。

## 数据存在哪

浏览器 localStorage，key 为 `gasnote.records.v1`，只在你当前这台机器的这个浏览器里。

**换浏览器、清缓存、换电脑都会丢。** 所以：

- 定期点「导出」，会下载一个 `gasnote-backup-YYYY-MM-DD.json`。
- 需要恢复时点「导入」选择那个文件即可。

浏览器不允许保存数据时（比如无痕模式），页面顶部会出现黄色横幅，此时记录只在当前页面有效，
刷新即丢，请立刻导出。

导入是「替换」而不是「合并」：会先用文件里的记录**整体替换**现有记录。导入前会弹确认框，
且**只有整个文件校验通过才会写入**。文件有任何一条记录不合法，你的现有数据都不会被改动。

## 遇到数据读不懂的情况

如果 localStorage 里躺着本工具读不懂的数据（比如更新版本写入的），工具**不会**把它扔掉，
而是把原文备份到 `gasnote.records.v1.corrupt` 这个 key，并以空列表启动，同时在页面顶部用红色横幅告知。

注意：点「导出」导出的是当前列表，**不包含**这份副本。

## 开发

```
src/
├── lib/           纯逻辑层，不 import React、不碰 DOM
│   ├── format.ts    金额与日期的文本 ↔ 数值（可单测）
│   ├── stats.ts     统计纯函数（可单测）
│   ├── store.ts     持久化与导入校验（storage 是注入的，可单测）
│   ├── storage.ts   存储降级（无痕模式 → 内存）
│   ├── theme.ts     深浅色主题
│   └── types.ts     共享类型
├── components/    界面
│   └── ui/        shadcn 生成的组件源码（归你所有，可随意改）
└── test/          95 个单元测试
```

逻辑层刻意不依赖 React 也不碰 DOM，所以可以直接用 **Node 内置测试运行器**跑 ——
Node 24 原生支持 TypeScript 类型擦除，`node --test` 直接执行 `.ts`，不需要 vitest、
不需要 jsdom、不需要任何测试框架。

```bash
npm test
```

界面层没有自动化测试（零依赖时代搭 DOM 测试环境需要引入构建链，得不偿失；现在虽有构建链，
但仍未补上）。改动界面后请手动在浏览器里走一遍：

记一笔 → 跨月记账 → 切月份 → 切年份 → 删除 → 导出 → 导入一个损坏文件确认数据没被破坏。

## 已知取舍

- **打包产物 JS 392KB（gzip 130KB）**，全部来自 React + Base UI。选 React 组件库的直接代价，
  对一个小工具来说是偏重的。前一个零构建原生版本是 0KB，已打 tag `v1-zero-build` 存档。
- `src/components/ui/*` 是 shadcn **复制进仓库的源码**，不是 npm 依赖。
  升级用 `npx shadcn@latest add <name> --overwrite` 重新拉取。
