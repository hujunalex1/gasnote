# 加油记账

一个记录每次加油金额、按月/按年统计的小工具。零依赖、零构建，数据存在你自己的浏览器里。

## 怎么跑

```bash
cd gasnote
python3 -m http.server 8000
```

然后浏览器打开 <http://localhost:8000>。

> **不要双击 `index.html` 打开。** macOS 上 Safari 在 `file://` 协议下禁用 localStorage，
> 你的数据会存不住。必须经 HTTP 提供。

## 怎么用

- 在「记一笔」填日期和金额，点「记下」。金额只接受最多两位小数的数字（如 `320.50`）。
  带千分位的 `1,240.50`、带符号的 `¥320`、全角数字都会被**明确拒绝**，而不是猜着解析。
- 「本月」「本年」两张卡恒定显示**真实的**本月和本年合计，与下面的年份选择器无关。
- 柱状图显示所选年份 12 个月的分布，**点柱子**可在下面的明细区查看那个月的记录。
- 切换年份时月份保持不变（看 2026 年 10 月时切到 2025 就是 2025 年 10 月），便于同比。
- 删除记录：点「删除」后会就地变成「确认删除？」，避免误触。

## 数据存在哪

浏览器 localStorage，key 为 `gasnote.records.v1`，只在你当前这台机器的这个浏览器里。

**换浏览器、清缓存、换电脑都会丢。** 所以：

- 定期点「导出」，会下载一个 `gasnote-backup-YYYY-MM-DD.json`。
- 需要恢复时点「导入」选择那个文件即可。

浏览器不允许保存数据时（比如无痕模式），页面顶部会出现黄色横幅，此时记录只在当前页面有效，
刷新即丢 —— 请立刻导出。

导入是「替换」而不是「合并」：会先用文件里的记录**整体替换**现有记录。导入前会弹确认框，
且**只有整个文件校验通过才会写入** —— 文件有任何一条记录不合法，你的现有数据都不会被改动。

## 遇到数据读不懂的情况

如果 localStorage 里躺着本工具读不懂的数据（比如更新版本写入的），工具**不会**把它扔掉，
而是把原文备份到 `gasnote.records.v1.corrupt` 这个 key，并以空列表启动，同时在页面顶部用红色横幅告知。

## 开发

```bash
node --test        # 跑全部单元测试，不需要安装任何东西
```

源码是原生 ES Module，浏览器直接加载 `src/*.js`，没有构建步骤。
`package.json` 里只有 `"type": "module"`，**没有任何依赖，永远不会产生 `node_modules`**。

- `src/format.js` —— 金额与日期的文本 ↔ 数值转换（可单测）
- `src/stats.js` —— 统计纯函数（可单测）
- `src/store.js` —— 持久化与导入校验（可单测，storage 是注入的）
- `src/ui.js` —— 唯一接触 DOM 的文件，不做业务判断

界面层没有自动化测试（零依赖下搭 DOM 测试环境需要引入构建链，得不偿失），
改动界面后请手动在浏览器里走一遍：记一笔 → 切月份 → 切年份 → 删除 → 导出 → 导入。
