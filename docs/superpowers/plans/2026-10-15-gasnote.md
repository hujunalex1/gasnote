# 加油记账（gasnote）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个记录每次加油金额、并按月/按年统计的单页工具，零依赖、零构建、数据存 localStorage。

**Architecture:** 原生 ES Module 静态站点。所有"会算错"的逻辑（金额解析、日期换算、统计、导入校验）都抽成纯函数放在 `src/format.js` / `src/stats.js` / `src/store.js`，用 Node 内置 `node --test` 单测；`src/ui.js` 是唯一接触 DOM 的文件，不做业务判断，只手写 CSS 柱状图与表格。

**Tech Stack:** 原生 JavaScript（ES Module）、手写 CSS、Node 24 内置测试运行器。**无任何第三方依赖。**

**Spec:** `docs/superpowers/specs/2026-10-15-gasnote-design.md`

## Global Constraints

- **零依赖**：不安装任何 npm 包。仓库中永不出现 `node_modules`。
- **零构建**：没有打包、转译、压缩步骤。浏览器直接 `<script type="module">` 加载 `src/*.js` 源码。
- **复用同一份源码**：Node 测试与浏览器加载的是同一批 `.js` 文件，不存在"测试跑的是另一份代码"。
- 日期一律用字符串 `YYYY-MM-DD` 表示，**禁止用 `Date` 序列化结果当作日期值**。
- 金额一律以"元"存储，**任何求和/求平均必须先转成整数"分"**（`Math.round(amount * 100)`），最后再除回 100。
- localStorage key 固定为 `gasnote.records.v1`，损坏数据备份 key 固定为 `gasnote.records.v1.corrupt`，schema 版本固定为 `1`。
- 界面文案一律中文。
- 金额输入只接受 `/^\d+(\.\d{1,2})?$/`（去除首尾空白后）。
- 所有注释、变量名用英文；界面文案用中文。

## Review Focus

以下是 spec 隐含、但单看每条任务的测试容易漏掉、且**最可能真的坑到用户**的五类输入/状态。每一条都在其归属任务的测试里钉死。

1. **粘贴进来的金额不是裸数字** —— 用户从银行 App / 微信账单复制 `1,240.50`、`¥320`、或全角 `３２０`。期望：要么正确接受，要么**明确报错**；绝不能静默存成一个错的数。（→ Task 1）
2. **本地时区** —— 晚上 23:50 记账，用 UTC 派生的日期会记成第二天，把账记进错误的月份。期望：日期默认值永远是用户**本地**的"今天"。（→ Task 2）
3. **localStorage 写入失败** —— 无痕模式或配额耗尽时 `setItem` 抛异常。期望：**明确告知保存失败**，而不是让用户以为记上了、刷新后才发现没了。（→ Task 5）
4. **同一毫秒内的连续录入** —— 快速连点"记下"两次，基于时间戳生成的 id 可能撞车，删一条时两条一起消失。期望：id 永远唯一。（→ Task 5）
5. **跨年后的年份选择器** —— 记录都在 2026 年而当前已是 2027 年时，选择器必须同时给出 2026 和 2027；切到没有记录的 2027 年，页面显示 `¥0.00` 而不是 `NaN` 或崩溃。（→ Task 3 单测 + Task 7 手动验收）

```js
// 金额文本层：用户输入的文本 ↔ 数字 ↔ 显示文本。
// 这一层存在的意义是把"人会打错字"这件事挡在业务逻辑之外。

const AMOUNT_RE = /^\d+(\.\d{1,2})?$/;

/**
 * 把输入框里的文本解析成金额（元）。
 * 只接受裸数字，最多两位小数。千分位、货币符号、全角数字一律拒绝，
 * 而不是"尽力猜"——静默地把 1,240.50 解析成 1 比报错危险得多。
 */
export function parseAmountInput(raw) {
  const text = String(raw ?? '').trim();
  if (text === '') return { ok: false, error: '请填写金额' };
  if (!AMOUNT_RE.test(text)) {
    return { ok: false, error: '金额只能是最多两位小数的数字，例如 320.50' };
  }
  const amount = Number(text);
  if (!Number.isFinite(amount) || amount <= 0) {
    return { ok: false, error: '金额必须大于 0' };
  }
  return { ok: true, amount };
}

/**
 * 金额 → 显示文本，带 ¥ 前缀与千分位，固定两位小数。
 * 全程走整数"分"，避免浮点误差漏到界面上。
 */
export function formatMoney(amount) {
  const cents = Math.round(Number(amount) * 100);
  const sign = cents < 0 ? '-' : '';
  const abs = Math.abs(cents);
  const yuan = Math.floor(abs / 100);
  const frac = String(abs % 100).padStart(2, '0');
  const grouped = String(yuan).replace(/\B(?=(\d{3})+(?!\d))/g, ',');
  return `${sign}¥${grouped}.${frac}`;
}
```

```js
const DATE_RE = /^(\d{4})-(\d{2})-(\d{2})$/;

/**
 * Date 对象 → "YYYY-MM-DD"。
 * 一律读本地年月日分量，绝不碰 toISOString()——那是 UTC，
 * 会让晚上 23:50 记的账跑到第二天去。
 */
export function toISODate(dateObj) {
  const y = dateObj.getFullYear();
  const m = String(dateObj.getMonth() + 1).padStart(2, '0');
  const d = String(dateObj.getDate()).padStart(2, '0');
  return `${y}-${m}-${d}`;
}

/** 本地时区的今天。这是全项目唯一一处读系统时间的地方。 */
export function todayISO() {
  return toISODate(new Date());
}

/**
 * 校验 "YYYY-MM-DD"，并且确认这个日期在日历上真实存在
 * （2 月 30 日、4 月 31 日一律拒绝，闰年 2 月 29 日接受）。
 */
export function isValidDate(value) {
  const m = DATE_RE.exec(String(value ?? ''));
  if (!m) return false;
  const year = Number(m[1]);
  const month = Number(m[2]);
  const day = Number(m[3]);
  if (month < 1 || month > 12) return false;
  if (day < 1 || day > 31) return false;
  // new Date(y, m, 0) 得到第 m 个月的最后一天（m 是 1-based）
  const daysInMonth = new Date(year, month, 0).getDate();
  return day <= daysInMonth;
}
```

```js
// 纯统计函数：只吃数组、只吐数字和对象。
// 不碰 DOM、不碰 localStorage、不读系统时间——因此可以完整单测。

/** "2026-10-15" → "2026-10"。纯字符串截取，天然没有时区问题。 */
export function monthKey(dateStr) {
  return String(dateStr).slice(0, 7);
}

// 金额一律转成整数「分」再累加，避免浮点误差在几十条记录后漂出来。
const toCents = (amount) => Math.round(Number(amount) * 100);
const fromCents = (cents) => cents / 100;

/** 某个月（"2026-10"）的合计、次数、平均每次。无记录时全部为 0，绝不是 NaN。 */
export function monthlyTotal(records, ym) {
  let cents = 0;
  let count = 0;
  for (const r of records) {
    if (monthKey(r.date) === ym) {
      cents += toCents(r.amount);
      count += 1;
    }
  }
  const avg = count === 0 ? 0 : fromCents(Math.round(cents / count));
  return { total: fromCents(cents), count, avg };
}

/**
 * 某一年的汇总。months 恒定返回 12 项，没记录的月份是 { total: 0, count: 0 }，
 * 这样柱状图永远画得出 12 根柱子。
 */
export function yearlySummary(records, year) {
  const prefix = `${year}-`;
  const buckets = Array.from({ length: 12 }, (_, i) => ({ month: i + 1, cents: 0, count: 0 }));

  for (const r of records) {
    const key = monthKey(r.date);
    if (!key.startsWith(prefix)) continue;
    const index = Number(key.slice(5, 7)) - 1;
    if (!Number.isInteger(index) || index < 0 || index > 11) continue;
    buckets[index].cents += toCents(r.amount);
    buckets[index].count += 1;
  }

  let totalCents = 0;
  let count = 0;
  const months = buckets.map((b) => {
    totalCents += b.cents;
    count += b.count;
    return { month: b.month, total: fromCents(b.cents), count: b.count };
  });

  return { total: fromCents(totalCents), count, months };
}

/**
 * 年份选择器的选项，降序。
 * currentYear 作为参数传入而不是在这里读系统时间——保持本文件是纯函数。
 * 当前年份始终包含在内，否则用户在没有任何记录的年份里没法记账。
 */
export function allYears(records, currentYear) {
  const years = new Set([currentYear]);
  for (const r of records) {
    const y = Number(monthKey(r.date).slice(0, 4));
    if (Number.isInteger(y)) years.add(y);
  }
  return [...years].sort((a, b) => b - a);
}

/** 每月合计 → 0..1 的柱高比例。全零时返回全零，不做除以 0。 */
export function barHeights(months) {
  const max = months.reduce((acc, m) => Math.max(acc, m.total), 0);
  if (max <= 0) return months.map(() => 0);
  return months.map((m) => m.total / max);
}
```

```js
import { isValidDate } from './format.js';

export const STORAGE_KEY = 'gasnote.records.v1';
export const CORRUPT_KEY = 'gasnote.records.v1.corrupt';
export const SCHEMA_VERSION = 1;

let idSeq = 0;

/**
 * id 生成的回退路径：毫秒 + 自增序号 + 随机数。
 * 自增序号是关键 —— 它保证同一毫秒内连续调用也不会撞号。
 *
 * 导出它**只是为了让测试能真的跑到这条分支**：Node 里 crypto.randomUUID 必然存在，
 * 如果把它藏在 newId 内部，测试就永远只覆盖 UUID 那条路，回退路径写错了也发现不了。
 * 业务代码请用 newId()，不要直接调这个。
 */
export function newIdFallback() {
  idSeq += 1;
  return `r${Date.now().toString(36)}-${idSeq}-${Math.random().toString(36).slice(2, 10)}`;
}

/**
 * 生成记录 id。
 * crypto.randomUUID 只在 secure context 可用（http://localhost 算，局域网 IP 不算），
 * 所以必须有回退。
 */
export function newId() {
  const uuid = globalThis.crypto?.randomUUID?.();
  return typeof uuid === 'string' ? uuid : newIdFallback();
}

/** 单条记录的字段校验。返回错误描述，合法则返回 null。 */
function validateRecord(r) {
  if (typeof r !== 'object' || r === null || Array.isArray(r)) {
    return '不是一个对象';
  }
  if (typeof r.date !== 'string' || !isValidDate(r.date)) {
    return `日期不是合法的 YYYY-MM-DD：${JSON.stringify(r.date)}`;
  }
  if (typeof r.amount !== 'number' || !Number.isFinite(r.amount) || r.amount <= 0) {
    return `金额不是大于 0 的数字：${JSON.stringify(r.amount)}`;
  }
  return null;
}

/**
 * 校验并规整记录数组。
 *
 * 拒绝（整体失败，绝不返回半截结果）：元素不是对象、日期非法、金额非法。
 * 修补（不拒绝）：id 缺失或重复 → 补发；note 非字符串 → 补空串；金额归整到分。
 *
 * 为什么 id 只修补不拒绝：id 是内部实现细节，用户看不见也不该关心。
 * 它坏掉不该让整份备份作废——那会让用户手里唯一的一份备份变成废纸。
 */
export function normalizeRecords(input) {
  if (!Array.isArray(input)) return { ok: false, error: '`records` 不是数组' };

  const seen = new Set();
  const records = [];

  for (let i = 0; i < input.length; i++) {
    const r = input[i];
    const problem = validateRecord(r);
    if (problem) return { ok: false, error: `第 ${i + 1} 条记录有问题：${problem}` };

    let id = typeof r.id === 'string' && r.id !== '' ? r.id : newId();
    if (seen.has(id)) id = newId();
    seen.add(id);

    records.push({
      id,
      date: r.date,
      amount: Math.round(r.amount * 100) / 100,
      note: typeof r.note === 'string' ? r.note : '',
    });
  }

  return { ok: true, records };
}

/** 把 JSON 文本解析成记录数组，全部校验通过才返回 ok。 */
export function parseImport(jsonString) {
  let parsed;
  try {
    parsed = JSON.parse(jsonString);
  } catch {
    return { ok: false, error: '这不是一个合法的 JSON 文件' };
  }
  if (typeof parsed !== 'object' || parsed === null || Array.isArray(parsed)) {
    return { ok: false, error: '文件顶层应该是一个对象' };
  }
  if (parsed.version !== SCHEMA_VERSION) {
    return {
      ok: false,
      error: `文件版本是 ${JSON.stringify(parsed.version)}，本工具只认识版本 ${SCHEMA_VERSION}`,
    };
  }
  return normalizeRecords(parsed.records);
}

/** 记录数组 → 存储/导出用的 JSON 文本。 */
export function serialize(records) {
  return JSON.stringify({ version: SCHEMA_VERSION, records }, null, 2);
}
```

```js
/**
 * 把 localStorage 里的原始字符串解码成状态。
 * 纯函数——不写任何东西，方便单测。
 */
export function decodeStored(raw) {
  if (raw === null || raw === undefined || raw === '') {
    return { status: 'empty', records: [] };
  }

  let parsed;
  try {
    parsed = JSON.parse(raw);
  } catch {
    return { status: 'corrupt-format', records: [], raw };
  }

  if (typeof parsed !== 'object' || parsed === null || Array.isArray(parsed)) {
    return { status: 'corrupt-format', records: [], raw };
  }

  if (parsed.version !== SCHEMA_VERSION) {
    return { status: 'corrupt-version', records: [], raw };
  }

  const normalized = normalizeRecords(parsed.records);
  if (!normalized.ok) return { status: 'corrupt-format', records: [], raw };

  return { status: 'ok', records: normalized.records };
}

/** 探测 localStorage 是否真的可写（无痕模式、隐私设置都会让它抛异常）。 */
export function probeStorage(storage) {
  if (!storage) return false;
  const probeKey = '__gasnote_probe__';
  try {
    storage.setItem(probeKey, '1');
    storage.removeItem(probeKey);
    return true;
  } catch {
    return false;
  }
}

/**
 * 启动时读取数据。
 *
 * 遇到读不懂的数据时绝不静默丢弃：把原文备份到 CORRUPT_KEY，以空数据启动，
 * 并把情况作为 notice 交给 UI 去显示横幅。宁可让用户看到空列表并被告知，
 * 也不能让数据无声消失。
 *
 * notice.kind 取值：'storage-unavailable' | 'corrupt-version' | 'corrupt-format'
 */
export function load(storage) {
  if (!storage) {
    return { records: [], notice: { kind: 'storage-unavailable' } };
  }

  let raw;
  try {
    raw = storage.getItem(STORAGE_KEY);
  } catch {
    return { records: [], notice: { kind: 'storage-unavailable' } };
  }

  const decoded = decodeStored(raw);
  if (decoded.status === 'ok') return { records: decoded.records, notice: null };
  if (decoded.status === 'empty') return { records: [], notice: null };

  // 损坏：先备份原文。备份失败也要继续，不能因此把数据弄丢。
  try {
    storage.setItem(CORRUPT_KEY, decoded.raw);
  } catch {
    /* 忽略：备份失败不影响后续流程 */
  }

  return { records: [], notice: { kind: decoded.status, raw: decoded.raw } };
}

/** 写入数据。失败时返回可读的错误，绝不静默吞掉。 */
export function save(storage, records) {
  if (!storage) {
    return { ok: false, error: '浏览器不允许保存数据，本次记录只在当前页面有效。请点「导出」备份。' };
  }
  try {
    storage.setItem(STORAGE_KEY, serialize(records));
    return { ok: true };
  } catch {
    return {
      ok: false,
      error: '保存失败（可能是浏览器隐私模式或存储空间已满）。本次记录只在当前页面有效，请立刻点「导出」备份。',
    };
  }
}
```

```js
import { parseAmountInput, isValidDate, todayISO } from './format.js';

// ---- 存储：不可用时降级为内存，功能照常，只是刷新即丢 ----
function createMemoryStorage() {
  const map = new Map();
  return {
    getItem: (k) => (map.has(k) ? map.get(k) : null),
    setItem: (k, v) => map.set(k, String(v)),
    removeItem: (k) => map.delete(k),
  };
}

let storage = null;
try {
  storage = globalThis.localStorage ?? null;
} catch {
  storage = null;
}

let notice = null;
if (!probeStorage(storage)) {
  storage = createMemoryStorage();
  notice = { kind: 'storage-unavailable' };
}

const state = {
  records: [],
  year: new Date().getFullYear(),
  month: new Date().getMonth() + 1,
};

const $ = (id) => document.getElementById(id);

function renderBanner() {
  const el = $('banner');
  if (!notice) {
    el.hidden = true;
    return;
  }
  el.hidden = false;
  el.dataset.kind = notice.kind;
  if (notice.kind === 'storage-unavailable') {
    el.textContent = '浏览器不允许保存数据（可能是无痕模式）。本次记录只在当前页面有效，刷新即丢 —— 请点「导出」保存。';
  } else if (notice.kind === 'corrupt-version') {
    el.textContent = '检测到本工具更新版本写入的数据，当前版本读不懂，已保留原始副本（导出后可见）。为避免覆盖，列表暂时是空的。';
  } else {
    el.textContent = '本地数据已损坏，无法读取。原始副本已保留，未被覆盖。';
  }
}

function persist() {
  const result = save(storage, state.records);
  if (!result.ok) {
    notice = { kind: 'corrupt-format', message: result.error };
    const el = $('banner');
    el.hidden = false;
    el.dataset.kind = 'save-failed';
    el.textContent = result.error;
  }
}

function showEntryError(message) {
  const el = $('entry-error');
  if (!message) {
    el.hidden = true;
    el.textContent = '';
    return;
  }
  el.hidden = false;
  el.textContent = message;
}

function handleSubmit(event) {
  event.preventDefault();
  showEntryError('');

  const dateValue = $('entry-date').value;
  if (!dateValue) {
    showEntryError('请选择日期');
    return;
  }
  // <input type="date"> 正常只会给出合法值，这里是兜底：
  // 非法日期一旦落库，会污染整条按月份分组的统计链。
  if (!isValidDate(dateValue)) {
    showEntryError('日期格式不对，应为 YYYY-MM-DD');
    return;
  }

  const parsed = parseAmountInput($('entry-amount').value);
  if (!parsed.ok) {
    showEntryError(parsed.error);
    return;
  }

  state.records.push({
    id: newId(),
    date: dateValue,
    amount: parsed.amount,
    note: $('entry-note').value.trim(),
  });

  persist();

  // 日期重置为今天而不是保留上次的值——避免用户忘了改日期而把账记进错误的月份
  $('entry-date').value = todayISO();
  $('entry-amount').value = '';
  $('entry-note').value = '';
  $('entry-amount').focus();
}

function init() {
  const loaded = load(storage);
  state.records = loaded.records;
  if (loaded.notice) notice = { ...loaded.notice, ...(notice ?? {}) };

  renderBanner();

  $('entry-date').value = todayISO();
  $('entry-form').addEventListener('submit', handleSubmit);
}
```

```js
function makeDeleteControls(id) {
  const wrap = document.createElement('span');
  wrap.className = 'record-actions';

  const del = document.createElement('button');
  del.type = 'button';
  del.className = 'danger';
  del.textContent = '删除';

  del.addEventListener('click', () => {
    wrap.textContent = '';

    const prompt = document.createElement('span');
    prompt.className = 'record-prompt';
    prompt.textContent = '确认删除？';

    const yes = document.createElement('button');
    yes.type = 'button';
    yes.className = 'danger';
    yes.textContent = '是';
    yes.addEventListener('click', () => {
      state.records = state.records.filter((r) => r.id !== id);
      persist();
      renderAll();
    });

    const no = document.createElement('button');
    no.type = 'button';
    no.textContent = '否';
    no.addEventListener('click', () => {
      wrap.textContent = '';
      wrap.append(del);
    });

  });
```

```js
function handleExport() {
  const blob = new Blob([serialize(state.records)], { type: 'application/json' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `gasnote-backup-${todayISO()}.json`;
  a.click();
  URL.revokeObjectURL(url);
}

/**
 * 导入是唯一可能一次性毁掉全部数据的操作，所以：
 * 先全量解析校验（parseImport），通过了才覆盖。任何一步失败都保持现状不动。
 */
async function handleImportFile(event) {
  const file = event.target.files?.[0];
  event.target.value = ''; // 允许连续导入同一个文件
  if (!file) return;

  let text;
  try {
    text = await file.text();
  } catch {
    window.alert('读取文件失败。');
    return;
  }

  const parsed = parseImport(text);
  if (!parsed.ok) {
    window.alert(`导入失败，你的数据没有任何改动。\n\n原因：${parsed.error}`);
    return;
  }

  const confirmed = window.confirm(
    `将用文件里的 ${parsed.records.length} 条记录替换当前的 ${state.records.length} 条记录。\n\n此操作不可撤销，确定继续？`,
  );
  if (!confirmed) return;

  state.records = parsed.records;
  const result = save(storage, state.records);
  renderAll();
  window.alert(result.ok ? `已导入 ${parsed.records.length} 条记录。` : result.error);
}

function initImportExport() {
  $('export-btn').addEventListener('click', handleExport);
  $('import-btn').addEventListener('click', () => $('import-file').click());
  $('import-file').addEventListener('change', handleImportFile);
}
```
